# 川西小众摩旅路线候选库

## 来源与使用边界

本文件根据用户提供的《川西小众摩旅路线档案》整理。原档案称其于 2026-09-07 从抖音检索汇总,难度与风景评分来自视频标题、简介和公开路线常识,不是官方数据或本 skill 实测。

**这些记录只能用于发现候选路线。** 在加入正式路书前,必须补齐起终点、连续轨迹、近期路况、道路属性/通行限制、补给、撤退点和天气窗口。视频点赞量不参与安全判断。原视频失效、标题变化或评论区轨迹无法取得时,将候选标为 `unverified`。

## 筛选顺序

1. **信息完整性**:有明确起终点和可导入轨迹 > 只有路线名称 > 只有模糊地点描述。
2. **可通行性**:近期官方通告/现场渠道 > 近期多来源实测 > 单个历史视频。
3. **人车匹配**:骑手非铺装经验、组队情况、车型、轮胎、载重、续航和维修能力。
4. **撤退能力**:天气恶化、落石/塌方、河水上涨、车辆故障或高反时是否有明确退出点。
5. **风景偏好**:通过以上门槛后,再用雪山、草甸、海子、人文等偏好排序。

### 难度解释

- 1:档案声称全程铺装或普通车辆可达;仍需检查高海拔、弯道、暗冰和施工。
- 2:铺装为主、可能包含垭口或较长山路。
- 3:混合路况或牧道,需要非铺装经验。
- 4:大量非铺装、碎石或高海拔穿越;默认要求组队、真实轨迹与撤退方案。
- 5:极高不确定性或荒野穿越;只有满足完整安全门槛时才可列入正式方案。

## 技术路线进入正式路书的检查清单

- [ ] 起点、终点、关键岔路和连续 `route_geometry` 已取得,坐标系明确
- [ ] 近 72 小时天气/预警已查;近 7 天至少一条可追溯路况证据,或已向当地交警/路政/现场人员确认
- [ ] 道路属性、临时管制、保护区/牧场/施工限制已核验
- [ ] 油料、饮水、餐食、住宿/扎营和通信盲区已标记
- [ ] 至少两个撤退点或明确“无法中途退出”的风险说明
- [ ] 设定降雨、降雪、河水上涨、能见度、时间、车辆故障和人员症状的 no-go/掉头条件
- [ ] 技术难度 4–5 已确认组队、离线轨迹、基础维修与救援通信能力
- [ ] 为同区域准备铺装或低难度替代路线

任一关键项缺失时,只能输出“候选调研清单”,不能把路线写成已验证、可直接骑行的详细路书。
